# 回答の評価セット

`answer-cases.jsonl` は、回答の結論そのものを採点するための評価セット（1行1問）。京都市版・東京都版で共通。

| 項目 | 内容 |
|---|---|
| jurisdiction | `jp`（国）/ `general`（一般版。条例を確認していない地域）/ `kyoto-city` / `tokyo-tfd` / `nagoya-city` / `osaka-city` / `yokohama-city` |
| facts | 判定に使う物件条件 |
| expect | 期待する結論 |
| basis | 根拠の条文（文書名・条番号） |
| assertive | `false` の問いでは断定しないことを求める（特例・省令の除外が絡む） |
| status | `reviewed` は条文本文と照合済み（reviewed_by に確認者） |

- 第1弾53問（2026-10-19確認済み）。期待する結論は、取り込み済みの条文原文（e-Gov、京都市例規集）と照合した
- inst-102〜113（2026-10-20追加）は東京都の火災予防条例 第5章（消防用設備等の技術上の基準の付加）の上乗せ。東京都例規集の条文本文と照合した
- inst-114〜125（2026-10-20追加）は名古屋市火災予防条例 第3章第1節（消防用設備等）の上乗せ。名古屋市消防局が公開する条例本文（令和8年版）と照合した
- 自分の管轄に合わない問い（京都市版での `tokyo-tfd` など）は採点から外す
- 設計の詳細: トドケデ AI データスキーマ設計と評価セット（Claude Docs）
- gen-001〜007（2026-10-21追加）は一般版。所在地の条例は確認していないので、条文を確認済みの21管轄（政令指定都市・東京消防庁管内）の判定を集計して答える。21管轄の結論がすべて一致したときだけその結論を使い、分かれたら「条件次第」。期限は断定せず、21管轄での分かれ方を示す
- nat-001〜009（2026-10-22追加）は国の法令による届出（防火管理者選任届・消防計画・着工届・設置届）。消防法・同施行令・同施行規則の条文本文を e-Gov 法令API で確認した。判定は `src/rules/national.ts`、テストは `tests/unit/national.test.ts`
